# Dashboard Onboarding

Onboarding starts automatically on first dashboard launch.

1. Create the owner account.
2. Choose `LOCAL` or `REMOTE_CLIENT`.
3. Create a pairing code for the client mod.
4. Select `MICROSOFT` or `OFFLINE_SERVER`.
5. For offline mode, configure server address and nickname.
6. Create a client profile: Minecraft version, Fabric, Java.
7. Create a server profile: address, lobby behavior, limits.
8. Select brain mode: `BUILT_IN` or `EXTERNAL`.
9. Configure model budget or external brain endpoint.
10. Configure initial rights and restrictions.
11. Run readiness checks and start the first session.

Onboarding can be rerun later without deleting tasks or memory.
